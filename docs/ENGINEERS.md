# The engineers

All 38 engineers, with the system and station where you find them. You can say "Starling, take me to" followed by a first name, a last name, a nickname or the full name (for example *Felicity*, *Farseer*, *Dekker*, *the Dweller*, *Sarge*, *Tod McQuinn*).

Closer than 1000 light years she plots the system with the galaxy map (the auto plotter). Farther than that, she asks Spansh for a neutron route. You can change the 1000 on the Navigation page. You can also ask "Where is Felicity Farseer?".
