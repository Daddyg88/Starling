SHIP PICTURES
The Home page shows a picture of the ship you are flying. The pictures are in this folder, named after the ship with
letters and numbers only (anaconda.webp, cobra3.webp = Cobra Mark 3, type9heavy.webp, python2.webp = Python Mark 2).

To add or replace one: put a .png .jpg .jpeg or .webp picture in data/ship_pictures/ (it is kept when Starling updates)
using the same kind of name. A picture there is used before the one in this folder. With no picture she draws a plain outline.
