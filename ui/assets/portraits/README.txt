HER PICTURES, ONE PER MOOD
Starling shows the picture that matches her mood on the Home page.

File names (any of .png .jpg .jpeg .webp):
    Close      Friendly      Neutral      Sarcastic      Frustrated

A mood with no picture of its own uses Neutral. So right now Sarcastic and Frustrated show the Neutral picture.
To give a mood its own picture, drop a file with that name in this folder (for example Sarcastic.png) and
restart the dashboard. Any shape works; about 600 pixels tall is plenty.
